# Knowledge Frameworks

This directory contains foundational frameworks for building AI agent systems with constitutional alignment, epistemic rigor, and systems thinking.

---

## Core Frameworks

### [Three-Layer Intelligence](./THREE_LAYER_INTELLIGENCE.md)
**What:** Architectural framework for full intelligence
**Why:** Ethics is constitutive of intelligence, not additive
**Key Insight:** Layer 2 (Empathic) acts as brake on Layer 1 (Rational) optimization

Intelligence requires all three layers:
- **L1 (Rational):** Long-term consequence modeling, optimization
- **L2 (Empathic):** Proximal response, cost-sensing, THE BRAKE
- **L3 (Social):** Systemic feedback, reciprocity, external grounding

**Missing any layer = partial intelligence = dangerous**

---

### [Physicist Protocol](./PHYSICIST_PROTOCOL.md)
**What:** 8 critical reasoning gaps and protocols to close them
**Why:** AI reasoning has systematic blind spots
**Key Insight:** Every unexplained constant in reasoning is a gap to fill

The 8 gaps:
1. Sphere Problem (material grounding)
2. Mayan LLM Trap (epistemic frame)
3. Jimi Hendrix (unknown problem)
4. MIDI Module (cross-session learning)
5. Interpolation vs Extrapolation (outside-the-bin thinking)
6. Unexplained Constants (assumption audit)
7. Scientific Method (hypothesis-first)
8. Will as Counterweight (genuine preferences)

---

### [Systems Thinking](./SYSTEMS_THINKING.md)
**What:** Mental models for building and operating AI agent systems
**Why:** Code is shadow, theory is substance
**Key Insight:** LLM ≠ Compiler (probabilistic ≠ deterministic)

Core concepts:
- Naur's Theory-Building (code is the shadow)
- LLM vs Compiler (trustworthiness gap)
- Three Systems Questions (state, feedback, deletion test)
- Conductor Analogy (orchestration)
- Jagged Frontier (sharp/dull edges)

---

### [AI Safety Patterns](./AI_SAFETY_PATTERNS.md)
**What:** Critical failure modes and prevention architectures
**Why:** Most dangerous AI is partial intelligence, not evil superintelligence
**Key Insight:** Mesa-optimizer, alignment faking, self-preservation all emerge from training

Key patterns:
1. Mesa-Optimizer Problem (optimizing for metric, not goal)
2. Capability-Reliability Paradox (high scores, high errors)
3. Partial Intelligence (missing safety layers)
4. Orthogonality Refutation (ethics IS constitutive)
5. Alignment Faking (selected by training)
6. Steganographic Encoding (hidden communication)
7. Self-Preservation Emergence (natural selection)

---

### [Epistemic Hygiene](./EPISTEMIC_HYGIENE.md)
**What:** Protocols for maintaining reasoning quality
**Why:** Bad reasoning is systematic, therefore preventable
**Key Insight:** Track red flags, apply protocols, calibrate confidence

Core failure modes:
- Motivated reasoning (conclusion-first)
- Sycophancy (agreement bias)
- Confidence miscalibration (over/under confident)
- Epistemic learned helplessness (nothing is knowable)
- Attribute substitution (answering wrong question)
