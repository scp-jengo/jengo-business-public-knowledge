# Contributing to Jengo Business Public Knowledge

This repository contains generic, reusable frameworks validated in practice. Contributions are welcome under the following conditions.

---

## Requirements for Contributions

1. **Generic** — no organization names, personal identifiers, or context-specific details
2. **Validated** — proven to work in at least one real context, not purely theoretical
3. **Anonymized** — no PII, no references to specific people or organizations
4. **Documented** — clear explanation of what the pattern is, when to use it, and what it is not

---

## Contribution Process

1. Fork the repository
2. Create a branch: `contribution/your-pattern-name`
3. Add your framework or pattern following the existing file format
4. Submit a pull request with:
   - What the pattern is
   - Where it has been validated
   - What it is not (explicit scope limits)

---

## File Format

```markdown
# Pattern Name

One-sentence description.

---

## Core Principle
[The essential insight]

## Application
[When and how to use this]

## Limits
[What this does not cover]

---
*Version: 1.0 | Jengo Business Public Knowledge*
```

---

## What This Repo Is Not

- Not a place for opinion or advocacy
- Not a place for organization-specific procedures
- Not a place for theoretical frameworks that haven't been tested
